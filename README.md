## 🚀 Projects

### [Awaaz](https://awaaz-32mv.onrender.com) — AI-powered government complaint platform
> *"TurboTax for filing government complaints in India"*

68% of cybercrime victims in India never report because the process is too painful. Awaaz fixes that — describe your problem in plain language, get a legally sound complaint letter drafted by AI, the right authority identified, and a step-by-step filing guide.

- Built with **FastAPI + Groq (Llama 3.3 70B)** for under-2-second AI responses
- Supports 7 complaint categories: cybercrime, consumer, RERA, RTI, railways, police, municipal
- Multi-language support: English, Hindi, Malayalam, Tamil, Telugu, Kannada
- PDF export, WhatsApp sharing, voice input, complaint tracking dashboard
- Automated tests (pytest), rate limiting, PostgreSQL in production

[GitHub](https://github.com/rahulkmilan/awaaz) · [Live](https://awaaz-32mv.onrender.com)

---

### [Carbook](https://carbook-modern.vercel.app) — Concurrency-safe peer-to-peer car rental
> *Backend-focused system designed around real-world edge cases*

Not just a CRUD app — built to handle concurrent booking conflicts, payment race conditions, and failure-safe transaction flows with production-grade data integrity.

- **Idempotent payment processing** via Razorpay — ensures a booking confirms exactly once
- **Graceful suspension model** instead of destructive deletes to preserve financial history
- **Server-side pricing engine** — zero client trust for all pricing and duration logic
- **State-driven booking lifecycle**: Pending → Confirmed → Completed → Cancelled
- Stack: **React + Django REST Framework + PostgreSQL** deployed on Render/Vercel/Supabase

[GitHub](https://github.com/rahulkmilan/carbook-modern) · [Live](https://carbook-modern.vercel.app)
